# MediPredict — Clean Frontend

A Vite + React + TypeScript + Tailwind CSS project. No Supabase, no backend, no broken auth.

## Quick Start

```bash
npm install
npm run dev
```

## What's Included

- Full UI design with medical theme (light/dark mode)
- All shadcn/ui components
- Pages: Landing, Login, Register, Dashboard, Prediction Form, Results, History, Medical Profile, ML Predict
- Mock auth using localStorage (sign up → instantly logged in)
- In-memory prediction storage (data persists for the session)
- Clean routing with React Router v6

## Stack

- Vite 5 + React 18 + TypeScript
- Tailwind CSS 3 + shadcn/ui
- React Router DOM v6
- lucide-react icons
- date-fns

## No Dependencies On

- Supabase
- Any backend API
- Admin-only routes
- External auth providers
